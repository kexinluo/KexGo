# KexGo MVP 验收清单

## 已在代码中覆盖

- [x] 拖入 / 选择 MP3，多选导入；同时兼容 FLAC / M4A / AAC / WAV / OGG / OPUS。
- [x] 自动关联同目录同名 `.lrc`（UTF-8 / UTF-16 / GB18030）。
- [x] 自动关联同名图片、`cover.*`，其次读取音频内嵌封面。
- [x] 封面复制到应用数据目录，曲库只保存音频路径与封面托管路径。
- [x] 有 LRC 直接解析显示；再次进入快速对轴，可逐行调整与整体偏移。
- [x] 无歌词时自动尝试 LRCLIB，也可手动找词、导入 LRC、粘贴纯文本。
- [x] 纯文本歌词清理空行、合并短句、长行提示；可直接进入跟打。
- [x] 空格逐行打点、自动跳下一行、不暂停；方向键按 100 / 10 / 500ms 步进。
- [x] 反应延迟补偿默认 `-150ms`；全局偏移；Z 撤销；R 回退 3 秒；S 保存。
- [x] 700ms 防抖自动保存草稿，重新进入时按歌词文本一致性恢复。
- [x] 保存为托管 LRC，可选同时写同目录 `.lrc`，并支持另存 / 导出。
- [x] 播放、暂停、上一首、下一首、进度拖动、音量、封面/歌曲信息显示与轻量编辑。
- [x] 记住上次曲目与播放位置、音量与补偿设置。
- [x] 无平台音频爬虫；无绕过付费；无在线音频下载。

## 桌面端人工验收（需 Rust / MSVC 环境）

1. `pnpm tauri dev` 启动桌面窗口。
2. 准备 `song.mp3` + `song.lrc` + `cover.jpg` 同目录文件，拖入窗口。
3. 确认曲库出现歌曲、封面显示、歌词高亮随播放滚动。
4. 删除或改名 LRC 后重新导入，确认自动请求 LRCLIB；若网络不可用，粘贴纯文本。
5. 播放歌曲，按空格逐行打点，方向键修正，Z 撤销，S 保存，检查应用数据目录的 `lyrics/{id}.lrc`。
6. 勾选 sidecar 再保存，检查原歌曲目录出现同名 `.lrc`。
7. 重新启动应用，确认曲目与播放位置恢复，未保存的对轴内容可从草稿恢复。

## 已知构建限制

当前构建容器没有 MSVC Build Tools；Rust 编译检查使用其已有的 GNU 工具链完成。发行版 `.exe / .msi` 仍需要在具备 MSVC + Rust stable + WebView2 的 Windows 机器上执行 `pnpm tauri build` 生成。
